# Thirty

Pequeña red social nostálgica para amigos, inspirada en la experiencia de las redes sociales españolas de finales de los 2000.

## Versión

- **v0.1.0**
- **Fecha:** 06/08/2026

## Estado actual

Demo estática publicada con GitHub Pages. Incluye inicio y tablón, perfil, mensajes, gente, fotos, eventos, búsqueda y chat simulado.

No utiliza servidor, API, cuentas ni base de datos. Los cambios de la demo se almacenan únicamente en `localStorage` dentro del navegador.

La versión anterior de Colorines se conserva en la rama `backup/colorines-2026-08-06`.
